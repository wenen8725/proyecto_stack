# Alarma de Seguridad Doméstica
 
Equipo: TechGuard
 
## Integrantes
- Integrante 1 – Scrum Master: crea el repo, agrega colaboradores, coordina y hace merges.
- Integrante 2 – Desarrollador: código en C++, diagrama de flujo, simulación en Wokwi.
- Integrante 3 – Hardware: define componentes, presupuesto y arma el circuito.
## Problemática
Detectar intrusos en una zona del hogar cuando no hay nadie, avisando con luz y sonido.
 
## Requerimientos funcionales
- Botón para activar/desactivar la alarma.
- Sensor PIR para detectar movimiento.
- LED RGB: verde si está seguro, rojo si detecta intruso.
- Buzzer que suena si hay movimiento, con tono ajustable por potenciómetro.
## Requerimientos no funcionales
- Responder en menos de 1 segundo.
- Código comentado y fácil de leer.
- Alimentación USB de 5V.
## Historia de usuario
Como propietario de una vivienda, quiero que el sistema active luces y sonido al detectar un intruso, para darme cuenta y disuadir el acceso.
 
## Componentes
| Componente | Función |
|---|---|
| Botón | Activar/desactivar alarma |
| Sensor PIR | Detectar movimiento |
| Potenciómetro | Ajustar tono del buzzer |
| Buzzer | Emitir sonido |
| LED RGB | Indicar estado (verde/rojo) |
 
## Presupuesto estimado
Total: $32.500 ARS (Arduino Uno, sensor PIR, potenciómetro, buzzer, LED RGB, protoboard y cables).
